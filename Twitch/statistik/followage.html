01 / Voraussetzungen

Was vorher vorhanden sein muss

  1. Streamer.bot muss mit deinem Twitch-Konto verbunden sein. Die Followage-Info kommt direkt von der Twitch-API, es braucht keine Zusatz-Tools.
  2. Wie alle Commands aus dieser Sammlung kommt der Followage-Command importiert deaktiviert an. Aktiviere ihn nach dem Import per Rechtsklick unter Commands.
  3. Der Command hat einen User-Cooldown von 30 Sekunden: Dieselbe Person kann die Abfrage nicht in rapidem Feuer spammen.

02 / Import

Import-Key in Streamer.bot einfügen

Das Paket landet über Import → Import from Clipboard in Streamer.bot: eine Action samt Followage-Command und Trigger.

  1. Öffne Streamer.bot.
  2. Klicke oben auf Import.
  3. Wähle Import from Clipboard.
  4. Kopiere hier den Import-Key und füge ihn in Streamer.bot ein.
  5. Bestätige den Import.

Nach dem Import liegen unter Commands ein disabled Command Followage mit !followage und !age bereit, dazu die Action Followage mit den zwei Sub-Actions.

Followage

Enthalten: der Command !followage/!age (importiert deaktiviert, Cooldown 30 s pro User) und die Action, die Followage abfragt und als Reply beantwortet.

03 / Nachricht anpassen

Bot-Nachricht hier einstellen

Passe die Chat-Antwort hier an. Deine Nachricht landet ungeändert in Streamer.bot: Text links kopieren, im Feld der Sub-Action Twitch → Chat → Send Message to Channel der Action Followage einfügen und mit Ok bestätigen. Die Platzhalter %user% (Zuschauername) und %followAgeLong% (Folge-Dauer) ersetzt Streamer.bot beim Senden.

Eigene Werte

Die Vorschau links zeigt 1:1 die Nachricht, die kopiert wird.

04 / Was die Action macht

Der Ablauf im Detail

Zwei Sub-Actions, mehr braucht es nicht:

SchrittSub-ActionWas passiert
1Twitch → Get Followers AgeLiest die Follow-Dauer des anfragenden Users (%user%) und legt die Platzhalter an, u.a. %followAgeLong%.
2Twitch → Send Message to Channel (Reply)Postet deine Nachricht als direkte Antwort auf die !followage-Nachricht (%msgId%).

Gut zu wissen

%followAgeLong% liefert die Dauer in langem Format (z. B. „2 Jahre 3 Monate 12 Tage"). Kurzformate und andere Varianten des Platzhalters stellst du in der Get-Followers-Age-Sub-Action um, wenn du sie brauchst.

Checkliste

  1. Command Followage ist unter Commands aktiviert.
  2. Action Followage zeigt den Trigger Command Triggered (Followage).
  3. Deine angepasste Nachricht steht in der Send-Message-Sub-Action.
  4. Ein Test mit !followage im Chat beantwortet die Nachricht direkt.

05 / Abschluss

Kontrolle vor dem ersten Live-Test

Checkliste

  1. Der Followage-Command ist unter Commands per Rechtsklick aktiviert.
  2. Die Nachricht aus Schritt 03 sitzt in der Sub-Action Twitch → Chat → Send Message to Channel;
  3. !followage im Chat ausprobieren: der Bot antwortet als direkte Reply mit deiner Nachricht.

Typische Probleme

  1. Bot antwortet nicht? Command aktivieren (Rechtsklick) und prüfen, ob der Streamer.bot-Stream-Trigger verbunden ist.
  2. Nur %user% im Chat? Der Get-Followers-Age-Schritt fehlt oder steht hinter der Send-Message-Sub-Action: Reihenfolge prüfen.
  3. Hotkeys spammen? Der 30-Sekunden-User-Cooldown ist im Command aktiv; prüfe ihn im Command-Editor unter Cooldowns.
