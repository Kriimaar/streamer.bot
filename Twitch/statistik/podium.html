01 / Voraussetzungen

Was vorher vorhanden sein muss

  1. Streamer.bot ist mit deinem Twitch-Konto verbunden, oben rechts zeigt es Connected.
  2. Auf Twitch existieren drei Kanalpunkte-Belohnungen Erster, Zweiter und Dritter. Trage ihre Reward-IDs im Anpassungs-Abschnitt ein.
  3. Die drei Rewards stehen in Twitch zunächst auf aktiviert: der Import kümmert sich um das Aktivieren und Pausieren im Betrieb.

02 / Import

Import-Key in Streamer.bot einfügen

Der Import enthält drei Actions: die Reward-Einlösung, den Streamstart-Reset und das Firstboard per Command. Nach dem Import vergeßt die Reward-IDs, aber nicht.

Import

  1. Öffne Streamer.bot und klicke oben auf Import.
  2. Wähle Import from Clipboard.
  3. Klicke hier auf Import-Key kopieren.
  4. Füge den Key in Streamer.bot ein und bestätige den Import.
  5. In den drei Actions First Rewards Redemption, First Rewards Stream Start und First Board sitzt jeweils eine Execute-C#-Sub-Action.
  6. Öffne jede Sub-Action und kompiliere den Code: Find Refs, Compile, Save & Compile.

03 / Rewards zuweisen

Die drei Reward-IDs eintragen

Reward-IDs kopieren

  1. Öffne in Streamer.bot Platforms → Twitch → Channel Point Rewards.
  2. Wähle deinen Erster-Reward und kopiere die Reward-ID. Wiederhole das für Zweiter und Dritter.

IDs eintragen

  1. Öffne die Action First Rewards Redemption.
  2. Aktiviere in der Redemption-Action die Trigger, indem du sie auf deine drei Rewards umbiegst (Kanalpunkte-Belohnung eingelöst, pro Reward ein Trigger).
  3. Öffne die Execute-C#-Sub-Action und ersetze HIER_REWARD_ID_ERSTER / ZWEITER / DRITTER oben im Code durch deine drei IDs.
  4. Kompiliere erneut: Find Refs, Compile, Save & Compile.

04 / Ablauf & Firstboard

Wie Erster, Zweiter, Dritter abläuft

Der Kreislauf

  1. Beim Streamstart setzt die Reset-Action die Claims zurück und schaltet nur den Erster-Reward aktiv. Zweiter und Dritter bleiben pausiert.
  2. Wer Erster claimed, bekommt 3 First-Punkte, und der Bot pausiert den Erster-Reward sofort.
  3. Gleichzeitig schaltet der Bot den Zweiter-Reward aktiv. Wer ihn claimed, bekommt 2 Punkte: danach geht der Dritter-Reward aktiv (1 Punkt).
  4. Ist der Dritte geclaimed, verschwindet die Belohnung. Bis zum nächsten Streamstart bleibt im Kanal kein toter Reward übrig.
  5. Pro Person und Stream ist nur ein Platz möglich. Wer schon etwas geclaimed hat, bekommt beim nächsten Versuch einen Hinweis statt Punkten.

!firstboard im Chat

  1. Das Command !firstboard oder !fboard zeigt die Top 10 aller First-Punkte.
  2. Das Command ist nach dem Import deaktiviert. Aktiviere es per Rechtsklick unter Commands.
  3. Hinweis: pro Person zählt der Standard: wer die Punkte anderer editieren will, kann das als Persisted Global firstPointsBoard von Hand tun.

Punkte auf einen Blick

PlatzPunkteDanach
Erster3Zweiter wird aktiv
Zweiter2Dritter wird aktiv
Dritter1Reward wird pausiert, Runde beendet

05 / Chat-Texte anpassen

Bot-Nachrichten hier einstellen

Der Editor generiert den kompletten Code der Redemption-Action: rechts einstellen, links kopieren und den ganzen Inhalt der Execute-C#-Sub-Action damit ersetzen. Die drei Reward-IDs trägst du rechts ein, sie landen automatisch im Code.

Eigene Werte

Änderungen übernehmen sich sofort in den Code links. Die Chat-Texte antwortet der Bot im Namen deines Twitch-Kontos.

06 / Abschluss

Kontrolle vor dem ersten Live-Test

Checkliste

  1. Alle drei importierten Actions zeigen eine Execute-C#-Sub-Action ohne Kompilierfehler.
  2. Die Redemption-Action ist mit deinen drei Rewards verbunden, die IDs stimmen mit dem Code überein.
  3. !firstboard ist aktiviert und antwortet mit dem aktuellen Stand.
  4. Stream startet → nur der Erster-Reward ist aktiv. Du selbst claimst → Zweiter wird aktiv; ein zweiter Account claimt → Dritter wird aktiv, danach pausiert.

Typische Probleme

  1. Reward-Trigger feuern nicht? Prüfe, ob die Redemption-Action auf deine Rewards verweist und der Streamer.bot-Stream-Trigger aktiv ist.
  2. Reward pausiert, aber kein nächster geht aktiv? Reward-ID-Konstanten im Code mit den echten IDs vergleichen (Schreibweise exakt!).
  3. !firstboard antwortet nicht? Command per Rechtsklick aktivieren; im Trigger der Board-Action muss das Command-Trigger-Event sichtbar sein.
