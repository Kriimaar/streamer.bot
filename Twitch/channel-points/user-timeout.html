01 / Voraussetzungen

Was vorher vorhanden sein muss

Twitch-Verbindung

Streamer.bot muss mit deinem Twitch-Account verbunden sein. Der Helfer dazu findest du in Streamer.bot unter Platforms.

Streamer.bot-Belohnung

Die Kanalpunkte-Belohnung wird direkt in Streamer.bot erstellt. Nur Belohnungen aus Streamer.bot erlauben die automatische Punkterstattung.

02 / Action importieren

Import-Key in Streamer.bot einfügen

Der Import enthält die komplette Timeout-Action inklusive Schutzregeln und Punkterstattung. Deine eigenen Werte trägst du erst im Anpassungs-Abschnitt ein.

Import

  1. Öffne Streamer.bot.
  2. Klicke oben auf Import.
  3. Wähle Import from Clipboard.
  4. Klicke hier auf Import-Key kopieren.
  5. Füge den Key in Streamer.bot ein und bestätige den Import.
  6. Prüfe unter Actions, ob die Action vorhanden ist.

03 / Kanalbelohnung erstellen

Reward in Streamer.bot anlegen

Die Belohnung entsteht in Streamer.bot selbst. Nur so kann Streamer.bot eingesetzte Punkte bei abgelehnten Timeouts automatisch zurückzahlen.

Wichtige Einstellungen

FeldEinstellung
Reward NameFrei wählbar, zum Beispiel „60s Timeout“.
User Input RequiredAktivieren. Zuschauer geben damit den Namen des Ziel-Users ein.
CostPunktepreis der Belohnung.
Max per Stream / per UserOptional begrenzen, um Missbrauch einzudämmen.
Global CooldownOptional, Pausen zwischen Einlösungen in Sekunden.

04 / Trigger verbinden

Reward mit der Action verbinden

Verbindung herstellen

  1. Öffne unter Actions & Queues → Actions die importierte Action.
  2. Öffne im Bereich Triggers den vorhandenen Trigger.
  3. Prüfe, ob Source Twitch und Type Reward Redemption eingetragen sind.
  4. Wähle bei Reward die eben erstellte Kanalbelohnung aus.
  5. Bestätige mit Ok und speichere die Action.

Code einfügen

  1. Öffne die Sub-Action Execute Code.
  2. Ersetze den Inhalt komplett durch den generierten Code aus dem Anpassungs-Abschnitt.
  3. Klicke unten links erst Find Refs, danach Compile.
  4. Ohne Fehler: Save & Compile.

05 / Anpassen

Dauer, Schutzregeln und Texte einstellen

Alle Felder rechts fließen direkt in den Code links ein. Änderungen werden nur lokal in deinem Browser gespeichert.

Timeout-Einstellungen

Jede Änderung wird sofort in den Code übernommen.

Maximal 14 Tage laut Twitch, also 1.209.600 Sekunden.
Von Mods-Timeouts wird abgeraten: Ein Timeout gegen dein Moderationsteam kann die Moderation deines Chats lahmlegen.
Chat-Antwort, wenn keine Eingabe mitgeschickt wurde.
Chat-Antwort, wenn der Ziel-User auf Twitch nicht existiert.
Chat-Antwort, wenn das Ziel ein Moderator ist.
Chat-Antwort, wenn das Ziel ein VIP ist.
Chat-Antwort nach erfolgreichem Timeout.

06 / Test & Probleme

Kontrolle vor dem ersten Live-Test

Checkliste

  1. Reward ist in Streamer.bot angelegt und aktiviert.
  2. Trigger zeigt bei Criteria den Reward an.
  3. Code kompiliert ohne Fehler.
  4. Test Trigger auslösen und das Timeout im Chat prüfen.

Typische Probleme

  1. Punkte werden nicht erstattet? Die Belohnung muss in Streamer.bot erstellt sein, nicht auf Twitch.
  2. Timeout passiert nicht? Prüfe, ob Streamer.bot Moderator in deinem Channel ist.
  3. Falscher User? Im Code-Generator bei CHAT-TEXT 2 · NUTZER NICHT GEFUNDEN prüfen, ob der Platzhalter {user} enthalten ist.
