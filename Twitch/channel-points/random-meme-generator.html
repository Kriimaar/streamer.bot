Random
Meme.

Mit dieser Funktion lösen Zuschauer eine Kanalpunkte-Belohnung aus. Streamer.bot wählt zufällig einen Clip aus deinem Meme-Ordner und spielt ihn über OBS ab. Weitere Einlösungen landen in einer Warteschlange, jeder Clip wird nur einmal hintereinander abgespielt und seine Länge automatisch erkannt.

02 / Voraussetzungen

Was vorher vorhanden sein muss

  1. Eine vorhandene OBS-Szene plus eine Medienquelle, über die die Clips laufen.
  2. Streamer.bot übernimmt die Auswahl der Videos, steuert OBS und reagiert auf deine Twitch-Belohnung.
  3. Ein Ordner auf deinem PC mit MP4-, MOV-, MKV- oder WEBM-Dateien. MP4/H.264/AAC ist am unkompliziertesten.
  4. Der Import-Key weiter unten enthält die komplette Action inklusive Queue-Ablauf, Medienwechsel und dynamischer Clipdauer.

03 / OBS Medienquelle

Meme Player in OBS anlegen

Die Medienquelle kann direkt in einer vorhandenen Stream-Szene liegen. Soll der Clip in mehreren Szenen erscheinen, füge dieselbe Quelle in den gewünschten Szenen hinzu.

Quelle erstellen

  1. Öffne die Szene, in der der Clip erscheinen soll.
  2. Im Bereich Quellen auf + klicken und Medienquelle wählen.
  3. Die Quelle Meme Player nennen. Der Name muss später exakt im Code stehen.
  4. Als lokale Datei einen beliebigen Clip aus deinem Meme-Ordner auswählen. Streamer.bot ersetzt diese Datei später automatisch.

Einstellungen der Medienquelle

  1. Lokale Datei aktivieren und einen beliebigen Clip als Platzhalter auswählen.
  2. Endlosschleife deaktiviert lassen.
  3. Wiedergabe bei Quellenaktivierung erneut starten deaktivieren.
  4. Nichts anzeigen, wenn Wiedergabe endet aktivieren.

Eigene SzeneOptional, wenn der Clip immer vollflächig oder als separates Layout erscheinen soll.

04 / Verbindung

OBS mit Streamer.bot verbinden

Der WebSocket ist die lokale Schnittstelle zwischen OBS und Streamer.bot. Einmal eingerichtet, bleibt die Verbindung bestehen.

In OBS

  1. Öffne oben Werkzeuge.
  2. Wähle WebSocket-Servereinstellungen.
  3. Aktiviere WebSocket-Server aktivieren.
  4. Lass den Port auf 4455.
  5. Aktiviere die Authentifizierung, notiere das Passwort und klicke Übernehmen.

In Streamer.bot

  1. Öffne links Stream Apps → OBS Studio.
  2. Rechtsklick in die Liste → Add.
  3. Version: v5.x; Host: 127.0.0.1; Port: 4455.
  4. Trage das Passwort aus OBS ein.
  5. Auto Connect on Startup und Reconnect on Disconnect aktiv lassen; dann OK.

05 / Action importieren

Import-Key in Streamer.bot einfügen

Der Import enthält die komplette Action inklusive sicherer Reihenfolge und dynamischer Videolänge. Deine eigenen Namen und Pfade trägst du erst im nächsten Schritt ein.

Import

  1. Öffne Streamer.bot.
  2. Klicke oben auf Import.
  3. Wähle Import from Clipboard.
  4. Klicke hier auf Import-Key kopieren.
  5. Füge den Key in Streamer.bot ein und bestätige den Import.
  6. Prüfe unter Actions, ob die Action vorhanden ist.

06 / Action anpassen

Ordner, Szene und Quelle eintragen

Trage deine Werte in die Felder rechts ein. Der Code links aktualisiert sich sofort und enthält danach exakt deine Namen. Änderungen werden nur lokal in deinem Browser gespeichert.

Eigene Werte

Jedes Feld wird 1:1 in den Code übernommen. Auf genaue Schreibweise achten.

So fügst du den Code ein

  1. Öffne die importierte Action in Streamer.bot.
  2. Doppelklicke die Sub-Action Execute Code.
  3. Ersetze den vorhandenen Inhalt komplett durch den generierten Code.
  4. Klicke unten links erst Find Refs, danach Compile. Erst wenn keine Fehler angezeigt werden: Save & Compile.
  5. Die Action setzt danach automatisch %memeScene%, %memeSource% und %memeVideo%.

07 / Twitch Kanalpunkte

Kanalpunkte-Reward verknüpfen

Belohnung anlegen

  1. Öffne Platforms → Twitch → Channel Point Rewards.
  2. Rechtsklick in die Liste → Create Reward.
  3. Vergib einen Namen, zum Beispiel „Random Meme“, und wähle den Preis.
  4. Speichern und die Belohnung aktivieren.

Trigger verbinden

  1. Gehe zu Actions & Queues → Actions und öffne die importierte Action.
  2. Oben im Bereich Triggers den vorhandenen Trigger auswählen.
  3. Bei Criteria die eben erstellte Kanalpunkte-Belohnung auswählen.
  4. Speichern. Die restliche Action bleibt unverändert.

08 / Abschluss

Kontrolle vor dem ersten Live-Test

Checkliste

  1. OBS Studio steht in Streamer.bot auf Connected.
  2. Szene und Medienquelle heißen exakt wie im Code.
  3. Starte einmal Test Trigger. Das Meme sollte jetzt in OBS angezeigt werden.

Typische Probleme

  1. Schwarzes Bild? Erhöhe in der importierten Action den Lade-Delay von 750 auf 1000 ms.
  2. Nichts passiert? Prüfe Ordnerpfad, Szenenname und Quellenname auf exakte Schreibweise.
  3. Clip spielt zu lange? Die Clipdauer wird automatisch gelesen; unterstützte Formate sind MP4, WEBM, MOV und MKV.
