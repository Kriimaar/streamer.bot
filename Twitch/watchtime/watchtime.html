02 / Voraussetzungen

Was vorher vorhanden sein muss

Streamer.bot

Streamer.bot legt für jeden Zuschauer eine eigene User-Variable an und zählt dort hoch. Die Twitch-Verbindung steht zum Glück schon, wie du sie von anderen Funktionen kennst.

Aktive Twitch-Verbindung

Das Bot-Konto muss mit deinem Chat verbunden sein, sonst kann es weder auf Commands antworten noch die Zuschauerliste empfangen.

Present Viewer aktiv

Die Zählung läuft komplett über die Present-Viewer-Funktion von Streamer.bot. In Schritt 03 zeige ich dir, wo du sie einschaltest.

Import-Keys

Der Import-Key weiter unten bringt Command, Counter und Leaderboard mit. Optional gibt es einen zweiten Key, der deine StreamElements-Watchtime importiert, inklusive Undo.

03 / Twitch-Einstellungen

Present Viewer aktivieren

Damit überhaupt etwas gezählt wird, muss Streamer.bot wissen, wer gerade in deinem Chat aktiv ist. Das erledigt die Present-Viewer-Funktion, du musst sie nur einmal in den Twitch-Einstellungen einschalten.

In Streamer.bot

  1. Öffne in der Leiste links Platforms und dann Twitch.
  2. Setze den Schalter bei Present Viewers auf Enabled.
  3. Schalte darin Live Update ein, damit die Zuschauerliste in Echtzeit von Twitch kommt.
  4. Stelle Update Interval auf 1 minute(s). Der Regler lässt sich zwischen 1 und 10 Minuten einstellen, 1 Minute ist am akkuratesten, weil so jedes Update mitgezählt wird.

04 / Import

Import-Keys in Streamer.bot einfügen

Beide Pakete landen über Import → Import from Clipboard in Streamer.bot. Der erste Key enthält die komplette Watchtime-Funktion, der zweite ist der optionale StreamElements-Import mit Undo.

Watchtime (Hauptfunktion)

Watchtime-Command, -Counter und -Leaderboard, fertig verdrahtet und importierbar.

StreamElements Watchtime Import (optional)

Holt deine bisherige Watchtime aus StreamElements rüber. Läuft beim Import etwas schief, rollt die Undo-Funktion alles zurück.

Import durchführen

  1. Öffne Streamer.bot.
  2. Klicke oben auf Import.
  3. Wähle Import from Clipboard.
  4. Klicke hier auf Import-Key kopieren (Hauptfunktion).
  5. Füge den Key in Streamer.bot ein und bestätige den Import.
  6. Wenn du magst, wiederhole das Ganze danach mit dem StreamElements-Key.

StreamElements-Import: nur einmal Test-Triggern

  1. Beide StreamElements-Aktionen laufen über Test-Trigger: Rechtsklick auf den Trigger, dann Test Trigger drücken.
  2. Den Import nur einmal triggern, pro Triggerung wird die komplette Watchtime importiert.
  3. Passt etwas nicht, macht die Undo-Funktion den Import wieder rückgängig (gleicher Weg über den Test Trigger).

05 / C#-Codes anpassen

Bot-Nachrichten und Werte einstellen

Alle drei Codes kannst du hier anpassen. Deine Werte kommen in die Felder rechts, der Code links zieht sofort nach. Die Zeilen mit ★ markieren genau die Stellen, an denen deine Eingaben landen. Gespeichert wird alles nur lokal in deinem Browser.

WATCHTIME COMMAND

Beantwortet den !watchtime-Command im Chat mit der gesammelten Watchtime des Zuschauers.

Eigene Werte

Jedes Feld wird 1:1 in den Code übernommen.

WATCHTIME COUNTER

Läuft bei jedem Present-Viewer-Update und zählt alle aktiven Zuschauer hoch. Du selbst als Broadcaster (Rolle 4) wird übersprungen, gezählt wird nur, wenn der Stream live ist.

Eigene Werte

Das Intervall sollte zum Update Interval aus Schritt 03 passen, bei 1 Minute also 60.

WATCHTIME LEADERBOARD

Zeigt die fleißigsten Zuschauer nach Watchtime an. Wer selbst nicht in den Top 5 steht, bekommt seinen Platz automatisch hinten drangehängt.

Eigene Werte

Pro Zeile ein Name. Wer hier nicht steht, taucht später im Leaderboard auf.

06 / In Streamer.bot einrichten

Actions aktivieren und Code kompilieren

Actions aktivieren

  1. Importierte Commands landen zunächst deaktiviert in Streamer.bot. Öffne Commands und schalte sie per Rechtsklick frei.
  2. Schau unter Actions & Queues → Actions, ob alle Watchtime-Actions angekommen sind.
  3. Command-Trigger und Present-Viewer-Trigger sind durch den Import schon verbunden, hier musst du nichts mehr anfassen.

C#-Code kompilieren

  1. Öffne jede importierte Action und doppelklicke die Sub-Action Execute Code.
  2. Ersetze den kompletten Inhalt durch den Code aus dem Editor oben (Schritt 05).
  3. Unten links zuerst Find Refs, dann Compile. Erst wenn keine Fehler mehr auftauchen: Save & Compile.
  4. Das Ganze für alle drei Codes: Command, Counter und Leaderboard.

StreamElements-Import einsetzen

  1. Die StreamElements-Aktionen laufen über Test-Trigger: Rechtsklick auf den Trigger → Test Trigger.
  2. Nur einmal triggern, jeder Trigger führt den kompletten Import aus.
  3. Rückgängig geht's genauso über die Undo-Action und Test Trigger.

So funktioniert das System

  1. Der Counter läuft automatisch bei jedem Present-Viewer-Update und erhöht %watchtimeSeconds% um dein Intervall.
  2. Der Command liest die Variable und antwortet im Chat.
  3. Das Leaderboard sortiert alle Werte, filtert Bots und dich als Broadcaster raus und postet die Top-Plätze.

07 / Abschluss

Kontrolle vor dem ersten Live-Test

Checkliste

  1. Present Viewers ist auf Enabled, Live Update an, Update Interval auf 1 Minute.
  2. Alle drei Codes kompilieren ohne Fehler.
  3. !watchtime und !wtboard in den Chat schreiben. Der Bot sollte bei beiden antworten, ganz am Anfang natürlich noch mit 0 Std. und 0 Min.

Typische Probleme

  1. Watchtime bleibt bei 0? Prüfe Present Viewers, Live Update und das Update Interval (Schritt 03), und ob im Counter-Editor dieselbe Intervall-Zahl steht.
  2. Bots im Leaderboard? Trag die Namen einfach in die Ausschluss-Liste des Leaderboard-Editors nach.
  3. Doppelt importiert? Den StreamElements-Import per Undo-Action (Test Trigger) zurücksetzen und einmal neu triggern.

08 / Auto Activate/Deactivate (optional)

Zählung nur schalten, wenn der Stream läuft

Wem die manuelle Aktivierung zu faul ist: Auto Activate/Deactivate Watchtime-Counting aktiviert bei Streamstart automatisch die Watchtime Counter-Action und legt sie bei Streamende wieder still. Das spart Anfragen des Bots an die Twitch-Server, wenn der Stream nicht läuft, und entlastet damit auch minimal den PC.

Was der Import anlegt

  1. Die Aktion Activate Counting feuert bei Stream Started und schaltet die Watchtime Counter-Action ein, war sie schon an, passiert nichts.
  2. Die Aktion Deactivate Counting feuert bei Stream Ended und schaltet die Counter-Action wieder aus.
  3. Die Counter-Action selbst bring der Import als deaktiviertes Duplikat mit (Gruppe Watchtime), sie wird automatisch zusammen mit dem System aktiviert.

So richtest du es ein

  1. Importiere den Key unten (Import → Import from Clipboard).
  2. Importiere, falls noch nicht geschehen, Ihren Haupt-Watchtime-Import (Schritt 04) und füge den Compilierin-Code in die neue, deaktivierte Counter-Action ein (Find Refs → Compile → Save & Compile).
  3. Den Counter nicht manuell aktivieren, das übernehmen Activate/Deactivate beim Streamstart/-ende.
  4. Testen: Stream starten, in Streamer.bot prüfen, dass die Counter-Action aktiv wird. Beim Streamende sollte sie sich automatisch abschalten.

Import

Der Import enthält nur die Schalt-Logik plus Counter-Duplikat, Command, Leaderboard und StreamElements-Import bleiben unberührt.
