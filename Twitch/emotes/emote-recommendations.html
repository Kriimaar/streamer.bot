01 / Actions importieren

Import-Key in Streamer.bot einfügen

Der Import enthält die Actions für Emote Vorschlag, Emote Approve, Emote Decline, Modadd Emote und Moddelete Emote.

Import

  1. Öffne Streamer.bot.
  2. Klicke oben auf Import.
  3. Wähle Import from Clipboard.
  4. Klicke hier auf Import-Key kopieren.
  5. Füge den Key in Streamer.bot ein und bestätige den Import.
  6. Prüfe danach unter Actions, ob die fünf Actions vorhanden sind.

02 / Trigger verbinden

Commands und Reward einrichten

Importierte Commands aktivieren

Die Commands sind bereits durch den Import-Key erstellt. Du musst sie nicht erneut anlegen, sondern nur aktivieren.

  1. Öffne links in der Streamer.bot-Navigation den Bereich Commands.
  2. Suche die importierten Commands.
  3. Klicke jeden benötigten Command mit der rechten Maustaste an.
  4. Wähle Enable, um ihn zu aktivieren.

Kanalpunkte-Reward einrichten

  1. Erstelle in Streamer.bot einen neuen Kanalpunkte-Reward für Emote-Vorschläge.
  2. Aktiviere die erforderliche Benutzereingabe, damit Zuschauer einen 7TV-Link einreichen können.
  3. Verknüpfe den Reward mit Emote Vorschlag.
  4. Erstelle den Reward in Streamer.bot selbst. Nur dadurch funktioniert die automatische Rückzahlung, falls ein Emote nicht verarbeitet werden kann.

Commands im Überblick

CommandWas macht der Command?
!emoteapprove <Nummer> [Name]Gibt einen offenen Emote-Vorschlag frei. Optional kann ein anderer Emote-Name vergeben werden.
!emotedecline <Nummer>Lehnt einen offenen Emote-Vorschlag ab und erstattet die eingesetzten Kanalpunkte.
!addemote 7TV-LINK [Name]Fügt ein 7TV-Emote direkt zum Channel-Emote-Set hinzu.
!deleteemote NAME
oder !deleteemote 7TV-LINK		Entfernt ein Emote anhand des Namens oder 7TV-Links.

Importierte Functions übernehmen

  1. Öffne nacheinander jede importierte Function.
  2. Öffne die jeweilige Sub-Action Execute C# Code.
  3. Klicke unten auf Find Refs.
  4. Klicke auf Compile.
  5. Klicke abschließend auf Save & Compile.
  6. Wiederhole dies für alle importierten Functions.

03 / 7TV Zugang einrichten

7TV-Zugang und Persisted Globals einrichten

Damit Streamer.bot Änderungen an deinem 7TV-Emote-Set ausführen kann, benötigt das System deinen 7TV Bearer Token und die ID des Emote-Sets deines Channels.

Token-Skript ausführen

  1. Öffne 7tv.app und melde dich an.
  2. Öffne die Entwicklerkonsole: Chrome, Edge und Brave mit F12 oder Strg + Umschalt + J; Firefox mit F12 oder Strg + Umschalt + K.
  3. Wechsle zum Tab Console.
  4. Kopiere das untenstehende Skript.
  5. Füge es in die Browser-Konsole ein und drücke Enter.
  6. Falls der Browser das Einfügen sperrt, tippe zuerst manuell allow pasting ein und bestätige mit Enter.

Ausgabe übernehmen

  1. Kopiere den Wert nach 🔑 Token gefunden: ohne Bearer.
  2. Wähle das Emote-Set, das mit deinem Twitch-Channel verbunden ist. Das ist nicht automatisch das Personal Emote Set.
  3. Lege die Werte anschließend als Persisted Globals in Streamer.bot an.

Token-Skript

Kopiere das Skript, führe es in der Browser-Konsole von 7tv.app aus und übernimm anschließend Token sowie Channel-Emote-Set-ID.
