02 / Spotify App

Spotify-App im Developer Dashboard anlegen

Erstelle oder öffne deine Spotify Developer App. Hinterlege dort die Redirect URI und kopiere danach Client ID und Client Secret für den nächsten Schritt.

http://127.0.0.1:4815/callback

Einrichtung im Dashboard

  1. Öffne das Spotify Developer Dashboard.
  2. Wähle deine App und öffne Settings.
  3. Füge die Redirect URI unter Redirect URIs ein und speichere.
  4. Kopiere Client ID und Client Secret für Schritt 02.

03 / Autorisieren & Globals

Autorisierung abschließen und Werte speichern

Der Helfer unten führt dich durch die Spotify-Anmeldung und zeigt dir am Ende alle fünf Werte, die du als Persisted Globals in Streamer.bot anlegst. Es werden keine Daten gespeichert, alles nur zum Kopieren.

Autorisierungs-Helfer

Wenn die Callback-Seite nicht lädt

Kopiere die vollständige Callback-URL aus der Adressleiste und füge sie oben ein.

Persisted Globals in Streamer.bot anlegen

  1. Öffne oben in Streamer.bot Global Variables.
  2. Wechsle in den Bereich Persisted Globals.
  3. Rechtsklick in die Liste → Add Variable.
  4. Klicke in der Tabelle auf Variable oder Value und füge die kopierten Werte ein.
  5. Auto Type darf nicht aktiviert sein. Mit OK speichern und für alle fünf Werte wiederholen.

04 / Streamer.bot importieren

Import-Keys einfügen

Alle drei Pakete werden nacheinander über Import → Import from Clipboard in Streamer.bot geladen. Danach den Execute-C#-Code jeder importierten Function kompilieren: Find Refs, Compile, Save & Compile.

Grundfunktionen

Token-Refresh sowie !song, !pause, !play, !skip und !vol.

Song Request

!sr mit Suche, Spotify-Link-Erkennung, Warteschlange und Antwort.

OBS Overlay

Action zum Erstellen und Aktualisieren von nowplaying.json.

05 / Song Request

Requests aus Chat oder Kanalpunkten

Twitch Chat

  1. Twitch Chat Command Trigger für !sr erstellen.
  2. Die Songrequest-Action zuweisen.
  3. Zuschauer geben Songname oder Spotify-Track-Link ein.

Kanalpunkte-Belohnung

  1. Unter Platforms → Twitch → Channel Point Rewards eine Reward anlegen.
  2. Benutzereingabe erforderlich aktivieren.
  3. Den Reward mit der Songrequest-Action verbinden.
  4. Den Eingabetext als rawInput übergeben.

Browser Source in OBS

  1. Im Editor nowplaying.html exportieren.
  2. In OBS eine Browserquelle erstellen und Lokale Datei aktivieren.
  3. Die exportierte Datei auswählen und Breite/Höhe aus dem Editor übernehmen.
  4. Seite bei Szenenaktivierung aktualisieren aktivieren.

Streamer.bot Timed Action

  1. Den im Editor erzeugten C#-Code für das Overlay übernehmen.
  2. Den absoluten Pfad zu nowplaying.json eintragen.
  3. Als Timed Action ausführen, zum Beispiel alle 5 Sekunden.
  4. Browser Source und Action müssen denselben JSON-Pfad verwenden.
