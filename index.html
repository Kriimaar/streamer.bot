02 / Das Projekt

Was dieses Projekt ist

Streamer.bot ist mächtig, aber der Einstieg ist steinig: Actions anlegen, Trigger verbinden, C#-Code verstehen. Diese Sammlung nimmt dir das ab. Du importierst fertige Funktionen per Import-Key, folgst der Anleitung und passt danach nur noch die Dinge an, die von Streamer zu Streamer unterschiedlich sind: Chat-Texte, Namen, Pfade, Variablen.

  1. Kein Login, keine Daten

    Es gibt keine Accounts, keine Cookies und keine Server. Alle Einstellungen und Textänderungen bleiben ausschließlich lokal in deinem Browser gespeichert. Löscht du den Browser-Cache, werden sie zurückgesetzt.

  2. Import statt Basteln

    Jede Funktion wird über einen Import-Key in Streamer.bot eingeladen. Der Key enthält Actions, Commands und Code im fertigen Zustand. Nach dem Import musst du nur noch aktivieren und verbinden.

  3. Alles anpassbar

    Auf jeder Funktionsseite gibt es einen Anpassungs-Abschnitt. Chat-Nachrichten, Variablen und Execute-C#-Code lassen sich dort bearbeiten und direkt kopieren.

04 / So funktioniert's

In vier Schritten zur eigenen Funktion

Der Ablauf

  1. Wähle auf dieser Seite eine Funktion und öffne ihre Seite.
  2. Lies die Anleitung und richte die Voraussetzungen ein, zum Beispiel OBS oder eine Spotify-App.
  3. Kopiere den Import-Key und lade ihn in Streamer.bot ein: Import → Import from Clipboard.
  4. Passe im Anpassungs-Abschnitt der Seite deine Chat-Texte, Pfade und Variablen an und kopiere den fertigen Code in Streamer.bot.

Gut zu wissen

  1. Importierte Commands werden in Streamer.bot zunächst deaktiviert angelegt. Aktiviere sie per Rechtsklick unter Commands.
  2. Execute-C#-Code muss nach dem Import kompiliert werden. Reihenfolge in der Sub-Action: Find Refs, Compile, Save & Compile.
  3. Alle Anpassungen auf diesen Seiten speichert dein Browser nur lokal. Sie sind also pro Gerät und Browser unterschiedlich.
